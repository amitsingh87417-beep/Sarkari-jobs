- Added filters for all 28 Indian States and 8 Union Territories.
- Admin job form supports state/UT selection and expanded job-detail fields.
- Job cards open a dedicated full details page with official apply/notification links and print/save-as-PDF.

- Typing practice reports actual WPM and accuracy without impossible speed promises.

- Runtime/API smoke testing requires npm install and configured environment variables. Syntax, JSON, region list, job/question data and project-file validation passed locally.
