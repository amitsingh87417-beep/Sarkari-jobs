New improvements:
- Added a guided daily skill-training routine for students.
- Added a one-click daily drill loader using the selected English or Hindi language.
- Added an on-screen English QWERTY keyboard coach that highlights the next expected key and provides basic finger guidance.
- Added a 30-minute endurance-test option for longer practice sessions.
- Added clearer desktop/laptop physical-keyboard guidance and Hindi input-method notes.
- Preserved existing exam profiles, passages, custom passages, strict mode, timer, WPM/CPM, accuracy, history, CSV export and printable result.

Important limitations:
- This remains a browser-based practice simulator, not an official examination platform.
- The visual next-key coach is for English QWERTY only. Hindi typing depends on the keyboard/input method configured on the student's computer; the page does not install or emulate InScript/Remington keyboard drivers.
- Practice history remains in local browser storage on each device and does not automatically sync between devices.
- Exam benchmarks and settings must be checked against the latest official recruitment notification.
